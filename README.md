# 💎 宝石消消乐 · Gem Crush

一个纯前端、零依赖的消除类网页小游戏。单文件 `index.html`，打开即玩。

## 玩法

点选两个**相邻**的宝石进行交换，凑成**三个或以上同色**即可消除得分。消除后上方宝石下落、顶部补充新宝石，可能触发**连锁消除（Cascade）**，连击越多得分加成越高。在限定**步数**内达到**目标分数**即过关。

## 功能

- 8×8 棋盘，6 种宝石
- 交换 / 三消·四消·五消判定 / 连锁消除
- 连击加成、分数与步数、关卡目标进度条
- 死局自动检测与洗牌、提示（高亮一组可消除的宝石）
- Web Audio 音效、下落与消除动画
- 响应式布局，支持桌面与移动端

## 本地运行

直接用浏览器打开 `index.html` 即可；或起一个本地静态服务器：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 部署

纯静态页面，可直接部署到 GitHub Pages / Vercel / Netlify。GitHub Pages：仓库 Settings → Pages → 选择分支根目录即可。

## 技术

原生 HTML + CSS + JavaScript，无框架、无构建步骤、无外部依赖。
